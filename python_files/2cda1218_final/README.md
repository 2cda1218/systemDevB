# 社会情報実践最終課題 2CDA1218
## 概要
このプロジェクトは，社会情報実践の最終課題である．

AIを用いた双方向インターフェースを持つアプリケーションの作成というテーマのもと，作成したDiscordとtransformersを用いたDiscord botである．

## 詳細
Discordは近年多くのユーザーが利用する無料チャット通話アプリである．このDiscordはユーザー向けにいくつかのSDKを用意しており，botはその一つである．AIの利用を併せる場合，モジュールの豊富さとbotの開発方法についての情報量からpythonを選択することがベストであると判断し，pythonでのDiscord botを作成した．

Discordアプリを利用することで，あらゆるプラットフォームでの利用を可能とする他，基本のインターフェースは用意されており，コマンドの実装によって双方向でのやりとりを簡単に実現した．

AIのモジュールとして**transformers**を採用し，GPT2がベースモデルである**rinna/japanese-gpt2-medium**によって日本語文章の生成を行うようにしている．

## 実装コマンド
* /omikuji

おみくじ生成を行うコマンド．おみくじの運勢だけであれば，pythonのリストからランダムに選択するだけで実装できる．しかし，AIに運勢以外のコメントを生成してもらうことで同じおみくじ結果はほぼ存在しない．また古いモデルだからこその精度の低い生成がおもしろさを生むことができるといったエンターテイメント性を確保できる．

* /stop

botをDiscord側から停止するコマンド．

## 使用方法

2cda1218_py_bot.pyの動作には`.env`内に含まれるTOKENを利用する必要がある．しかし，生成したTOKENをアップロードしてしまうとアプリケーションの乗っ取りが発生するリスクがあるため`.env`はGitHub上には掲載していない．そこで，以下に使用可能にするための方法をまとめる．

1. Discord Developer Portalからアプリケーションを生成し，TOKENの生成をします．

2. 2cda1218_py_bot.pyと同じ階層に`.env`ファイルを作成し，`TOKEN = "Your_TOKEN"`を記述した後`Your_TOKEN`の部分をDiscord Developer Portalで生成したTOKENに置き換えます．

3. Discord Developer Portalで必要なSCOPEとPERMISSIONを選択して生成されたURLを用いて自分のDiscordサーバーに追加します．
