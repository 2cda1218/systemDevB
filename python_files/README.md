## 2cda1218_final
2cda1218_final/2cda1218_py_bot.pyは社会情報実践の最終課題として作成したDiscord bot pythonプログラムである．

Discordとは近年多くのユーザーが利用する無料チャット通話アプリである．このDiscordはユーザー向けにいくつかのSDKを用意しており，botはその一つである．AIの利用を併せる場合，モジュールの豊富さとbotの開発方法についての情報量からpythonを選択することがベストであると判断し，pythonでのDiscord botを作成した．

Discordアプリを利用することで，あらゆるプラットフォームでの利用を可能とする他，基本のインターフェースは用意されており，コマンドの実装によって双方向でのやりとりを簡単に実現した．

AIのモジュールとして**transformers**を採用し，GPT2がベースモデルである**rinna/japanese-gpt2-medium**によって日本語文章の生成を行うようにしている．
