## BingoCard
BingoCardプロジェクトは社会方法実践の第六回課題として作成したプロジェクトである。<br>
前回同様Swingを採用し、GUIを作成した。<br>
現状として、カードのビンゴ機能は完成した。また、カードの固有値となるハッシュ値の生成も行うところまでは完成している。一方で、カードを複数生成しハッシュ値が重複していないかといった機能までは搭載できていない。
